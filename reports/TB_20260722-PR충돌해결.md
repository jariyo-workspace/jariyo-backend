## 개요
- `feature/reservation-availability` 브랜치에 `origin/master`를 병합하면서 발생한 충돌을 해결했습니다.
- 예약 가능 시간 API 코드가 최신 store 도메인 변경과 함께 컴파일되도록 호환 메서드/생성자를 최소 범위로 보완했습니다.

## 변경 파일
- `src/main/java/com/example/jariyo_backend/domain/availability/service/AvailabilityService.java`
- `src/main/java/com/example/jariyo_backend/domain/store/repository/*.java` (충돌 이후 호환 조회 메서드 추가)
- `src/main/java/com/example/jariyo_backend/domain/store/entity/*.java` (테스트/호환용 생성자 추가)
- `reports/TB_20260722-PR충돌해결.md`
- 그 외 `origin/master` 병합으로 반영된 충돌/비충돌 파일 일괄 포함

## 실행 명령
- `git fetch --unshallow origin`
- `git fetch origin master:refs/remotes/origin/master`
- `git merge --no-commit --no-ff origin/master`
- `./gradlew test --tests "*AvailabilityServiceTests"`
- `./gradlew test`

## 테스트 결과
- `./gradlew test --tests "*AvailabilityServiceTests"` 성공
- `./gradlew test` 성공

## 이슈
- `jariyo-docs` 서브모듈 포인터 충돌이 발생해 `origin/master` 포인터 기준으로 해결했습니다.

## 개요

자리요 백엔드의 AWS 배포 설계를 실제 구현 가능한 수준으로 구체화했다. 현재 MVP 동작은 유지하면서, `ALB -> ECS Fargate(API + Worker) -> RDS + Redis + DB Outbox`를 기준 권장안으로 확정하고 시스템 아키텍처, 운영 가이드, 배포 설계서를 보강했다.

## 이슈

- `jariyo-docs`는 서브모듈이라 루트 저장소와 별도로 브랜치와 PR를 관리해야 한다.
- 루트 저장소에는 이번 작업과 무관한 미추적 report 파일 2개가 남아 있어 포함하지 않았다.

## 후속 작업

- `jariyo-docs` 배포 설계 문서를 별도 커밋하고 PR로 올린다.
- 루트 저장소에서는 서브모듈 포인터와 작업 report를 연결하는 후속 커밋을 만든다.
- 이후 Terraform 또는 ECS 배포 자산을 만들기 위한 구현 작업을 별도 브랜치에서 시작한다.

## 셀프리뷰

- 현재 MVP 계약과 상태 전이를 바꾸는 내용은 넣지 않았다.
- 모바일 앱 백엔드라는 전제를 반영해 `CloudFront`는 권장안에서 제외하고 `WAF`는 확장 옵션으로 남겼다.
- API와 Worker 분리를 운영 단순성과 후처리 유실 방지 기준으로 정리했다.
- `./gradlew test`를 다시 실행해 현재 코드 상태와 직접 충돌하지 않는지 확인했다.

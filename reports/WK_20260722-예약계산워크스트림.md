# 개요

이슈 `#8`의 예약 계산 워크스트림을 구현했다.

`/api/v1/stores/{storeId}/availability` 조회 API를 추가했고, 매장 영업시간, 직원 근무시간, 일정 예외, 서비스 소요 시간, 기존 예약 점유 시간을 반영해 예약 가능 슬롯을 계산하도록 구성했다.

# 이슈

현재 MVP 구현은 `AVAILABLE` 슬롯만 반환한다.

`UNAVAILABLE`, `WAITLIST_AVAILABLE` 상태 반환은 예약 대기 워크스트림과 함께 후속 확장이 필요하다.

# 후속 작업

* 예약 생성 API에서 같은 슬롯 계산 규칙으로 최종 충돌 검증을 연결해야 한다.
* 운영 도메인 조회 API가 들어오면 매장, 서비스, 직원 데이터와 예약 계산 데이터를 실제 플로우로 연결해야 한다.
* 예약 대기 워크스트림에서 `WAITLIST_AVAILABLE` 노출 정책을 구체화해야 한다.

# 셀프리뷰

관련 문서 `04-api-spec.md`, `05-frontend-api-guide.md`, `07-backend-mvp-guide.md`를 이번 구현 기준으로 업데이트했다.

브랜치/커밋 작업은 아직 하지 않았고, 테스트는 `./gradlew test`로 확인했다.

남은 리스크는 매장 운영 조회 API와 예약 생성 API가 아직 없어서 현재 계산 API가 실제 데이터 입력 흐름과 완전히 연결되지는 않았다는 점이다.

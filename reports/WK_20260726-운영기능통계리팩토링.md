## 개요

운영 기능 및 통계 리팩토링 9단계로 관리자 운영 요약 통계 조회와 실패 작업 조회/재처리 기능을 추가했다. 기존 예약, 빈자리 제안, 현장 대기, 비동기 outbox 데이터를 관리자 관점에서 재사용할 수 있도록 공통 운영 서비스로 묶었다.

## 이슈

* 감사 로그 API는 문서에만 있고 아직 저장 모델이 없어 이번 단계 범위에서 제외했다.
* 실패 작업 목록은 현재 `limit` 중심의 단순 조회만 지원하고 `cursor` 기반 페이지네이션은 후속 작업으로 남겼다.

## 후속 작업

* `audit_log` 모델과 관리자 감사 로그 조회 API를 추가한다.
* 실패 작업 목록에 `cursor` 기반 페이지네이션과 무시 처리 기능을 추가한다.
* 직원별 통계, 서비스별 실제 소요 시간 통계를 운영 화면 요구사항에 맞게 확장한다.

## 셀프리뷰

* 관련 문서로 `04-api-spec.md`를 현재 구현 범위에 맞게 갱신했다.
* 관리자 API는 `StoreAuthorizationService.requireManager`를 사용해 권한 경계를 통일했다.
* 통계 계산은 현재 저장된 상태값과 시각 필드만 사용하도록 제한해 해석이 불안정한 데이터를 피했다.
* 운영 통계 정의는 MVP 기준 단순 집계이므로, 지표 산식이 확정되면 문서와 쿼리를 함께 보정해야 한다.

# 개요

GitHub 이슈 `#26 [FEAT] 내 예약 목록 cursor 페이지네이션`을 구현했다.
내 예약 목록에 `startAt DESC, id DESC` keyset pagination을 적용하고 상태·매장 현지 날짜 필터,
opaque cursor와 페이지 응답 계약을 연결했다.

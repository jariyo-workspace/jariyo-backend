## 개요

오랜만에 보거나 새로 보는 사람을 위해 자리요의 기획, 설계, 코드 진입 순서를 한 번에 정리한 온보딩 문서를 추가했다. 기존 기준 문서를 대체하지 않고, 어떤 문서를 어떤 순서로 읽고 어떤 코드와 테스트를 보면 되는지 안내하는 역할로 설계했다.

- `git branch --show-current`
- `git status --short`
- `git -C jariyo-docs checkout -b docs/onboarding-guide faf0a1e`
- `GRADLE_USER_HOME=/tmp/gradle-home GRADLE_DAEMON_BIND_ADDRESS=127.0.0.1 ./gradlew --no-daemon test`

## 이슈

- `jariyo-docs`는 서브모듈이라 루트 저장소와 별도로 브랜치와 PR를 관리해야 한다.
- 루트 저장소에는 이번 작업과 무관한 미추적 report 파일 2개가 남아 있어 포함하지 않았다.

## 후속 작업

- `jariyo-docs`용 온보딩 문서 변경을 별도 커밋하고 문서 PR로 올린다.
- 루트 저장소에서는 서브모듈 포인터와 작업 report를 연결하는 후속 커밋을 만든다.
- 필요 시 프론트엔드 또는 운영 전용 온보딩 문서를 별도 분리한다.

## 셀프리뷰

- 온보딩 문서는 새 기준 문서 `08`부터 `11`과 실제 코드 패키지 구조를 함께 참조하도록 작성했다.
- 현재 MVP 계약을 바꾸는 내용은 넣지 않았다.
- `./gradlew test`를 다시 실행해 현재 코드 상태와 직접 충돌하지 않는지 확인했다.

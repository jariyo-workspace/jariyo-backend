# 예약 홀드 생성·확정·만료

## 개요

이슈 #25에 따라 기존 즉시 확정 예약 API를 유지하면서 결제 또는 추가 확인에 사용할 수 있는 예약 홀드 생성, 확정, 만료 흐름을 추가했다. 홀드 확정과 만료는 예약 행 비관적 잠금으로 경합을 제어하고, 만료 시각이 지난 홀드는 상태 갱신 전에도 예약 충돌과 가용성 계산에서 제외한다.

코드 리뷰에서 확인된 고객 식별자 불일치도 함께 수정했다. `reservation.customer_id`는 모든 예약 생성·조회·취소·대기열 수락 경로에서 `customer_profile.id`를 사용한다.

## 변경 파일

- 예약 엔티티, 저장소, 예약 생성·확정·취소 서비스와 컨트롤러
- 예약 홀드 만료 스케줄러와 비동기 이벤트
- Flyway V7/V8 번호 정리 및 V9 고객 프로필 FK·홀드 제약 변경
- 예약 홀드 단위 테스트와 PostgreSQL 통합 테스트 시나리오
- 대기열 수락 예약의 고객 프로필 FK 회귀 테스트
- `jariyo-docs/docs/02-data-model.md`
- `jariyo-docs/docs/04-api-spec.md`

## 이슈

- 초기 통합 테스트에서는 Docker daemon 중지로 실행할 수 없었으나 Docker 재실행 후 전체 통합 테스트를 완료했다.
- 고객 FK를 `customer_profile(id)`로 통일하면서 기존 조회·대기열 수락 경로에 남아 있던 `users.id` 사용을 발견해 수정했다.

# 개요

공통 기반 워크스트림의 첫 작업으로 공통 에러 응답 작성 경로를 정리했다.
`GlobalExceptionHandler`, Spring Security 진입점/권한 거부 핸들러, 활성 사용자 검증 필터가 서로 다른 방식으로 에러 응답을 만들던 중복을 제거하고, 하나의 작성 컴포넌트를 사용하도록 통일했다.

# 이슈

- 작업 시작 시점에 `jariyo-docs` 디렉터리에 기존 사용자 변경사항이 있어 건드리지 않았다.
- 이번 작업은 동작 변경보다 공통 기반 내부 중복 제거가 목적이라 문서 수정은 진행하지 않았다.

# 후속 작업

- 공통 응답 포맷을 `jariyo-docs/docs/04-api-spec.md` 기준과 더 가깝게 맞출지 검토
- `requestId`, `details` 같은 공통 오류 메타데이터 도입 여부 결정
- 멱등성 처리와 권한 검증 실패 응답도 같은 공통 규약으로 확장

# 셀프리뷰

- 관련 문서(`06-backend-implementation-guide.md`, `04-api-spec.md`)를 확인하고 공통 기반 범위에 맞는 최소 리팩토링만 반영했다.
- `./gradlew test`를 실행해 회귀를 확인했다.
- `reports` 디렉터리와 작업 보고서를 생성했다.
- 문서와 외부 인터페이스를 바꾸지 않는 범위로 작업해 리스크를 줄였지만, API 응답 포맷 자체는 아직 문서와 완전히 일치하지 않으므로 공통 기반 후속 리팩토링이 필요하다.

# 개요

- GitHub 이슈 #40의 고객 예약 대기, 빈자리 제안, 현장 대기 MVP 흐름을 점검하고 기존 구조를 최소 범위로 보완했다.
- 예약 대기와 빈자리 제안 상세에 `resultingReservationId`를 노출하고 직원 참조 필드를 `displayName`으로 명세와 일치시켰다.
- 현장 대기 상태 전이와 대기 인원 재계산을 통합 테스트로 보강했다.
- 최신 `upstream/master`의 `audit_log` Flyway 마이그레이션을 재사용해 통합 테스트 스키마를 검증했다.

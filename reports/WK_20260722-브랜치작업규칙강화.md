# 개요

`AGENTS.md`에 `master` 또는 `main` 브랜치에서 직접 작업하지 말고, 작업 시작 전에 반드시 이슈용 브랜치를 생성하라는 규칙을 추가했다.

# 변경 파일

* `AGENTS.md`

# 실행 명령

```bash
./gradlew test
```

# 테스트 결과

`./gradlew test` 통과

# 이슈

현재 작업은 사용자 요청에 따라 `master` 브랜치에서 규칙 문구만 수정한 상태다.

# 후속 작업

* 이후 실제 구현 작업은 항상 이슈용 브랜치에서 시작해야 한다.
* 필요하면 같은 규칙을 `jariyo-docs` 쪽 가이드에도 같은 수준으로 맞출 수 있다.

# 셀프리뷰

브랜치 작업 규칙을 기존 커밋/PR 가이드 아래에 직접 추가해 해석 여지를 줄였다.

테스트와 보고서 작성 규칙도 함께 지켰다.

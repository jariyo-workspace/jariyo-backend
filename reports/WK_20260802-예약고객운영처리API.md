## 개요

이슈 `#36` 범위로 예약 고객 운영 처리 API를 구현했다. 운영자가 예약 고객을 체크인, 노쇼 처리, 서비스 시작, 서비스 완료할 수 있도록 예약 도메인 상태 전이와 공용 서비스 세션 완료 흐름을 추가했다.

## 이슈

- `service_session` 테이블이 기존에는 현장 대기 전용 구조여서 예약 고객 서비스 완료를 지원하도록 스키마를 확장했다.
- 기존 워킹트리에 있던 `jariyo-docs` 수정과 기존 미추적 보고서 파일은 건드리지 않았다.
- 문서(`jariyo-docs/docs/04-api-spec.md`, `06-backend-implementation-guide.md`)는 사전 확인했고, 이번 구현은 기존 명세 범위에 맞춰 진행해 별도 문서 수정은 하지 않았다.

## 후속 작업

- 예약 고객 체크인 가능 여부 조회 API가 필요하면 별도 이슈로 추가 구현
- 운영자 예약 상세 조회에서 새 상태 전이 결과가 충분히 노출되는지 검토
- 감사 로그 조회 화면에서 신규 액션명이 필요한지 확인

## 셀프리뷰

- 예약 고객 운영 처리의 핵심 상태 전이와 공용 서비스 완료 경로는 구현했다.
- 관련 테스트를 추가했고 전체 테스트를 통과시켰다.
- 문서 기준 구현 범위는 맞췄지만, 운영 화면에서 어떤 응답 필드를 실제로 더 요구하는지는 후속 UI 연동에서 재검증이 필요하다.

## 개요

AWS 기준 백엔드 시스템 리디자인 방향을 반영해 `jariyo-docs`의 백엔드 문서 체계를 재구성했다. 현재 구현된 MVP 동작은 유지한다는 전제 아래, 새로운 백엔드 기준 문서 4종을 추가하고 README의 메인 안내를 새 체계로 전환했다.

## 이슈

- `jariyo-docs`는 서브모듈이며 부모 저장소 기준으로 이미 추적 중인 변경으로 보인다.
- 루트 워크트리에 이번 작업과 무관한 미추적 report 파일 2개가 남아 있어 건드리지 않았다.

## 후속 작업

- 새 백엔드 기준 문서를 바탕으로 기존 `06`, `07` 문서의 상세 링크 정리 여부를 추가 판단한다.
- 필요 시 `04-api-spec.md`, `05-frontend-api-guide.md`와 새 백엔드 기준 문서 간 상호 참조를 보강한다.
- 권장 아키텍처를 실제 인프라 코드 또는 운영 체크리스트로 구체화하는 후속 작업을 분리한다.

## 셀프리뷰

- 문서 설계는 현재 MVP 계약을 변경하지 않는 방향으로 작성했다.
- 기존 백엔드 문서는 삭제하지 않고 legacy로 유지해 참조 경로를 보존했다.
- `./gradlew test`를 다시 실행해 현재 구현과 문서 리디자인이 직접 충돌하지 않는지 확인했다.

# 개요

- GitHub 이슈 #43의 빈자리 제안 거절 API와 대기 유지 정책을 구현했다.
- `keepWaitlistActive` 값에 따라 예약 대기를 `WAITING` 또는 `CANCELLED`로 변경한다.
- 기존 비관적 잠금, 영속 멱등성 처리와 제안 상태 이력을 재사용했다.

# 실행 명령

- `git pull --ff-only upstream master`
- `git submodule update --init --recursive`
- `.\gradlew.bat test`
- `.\gradlew.bat integrationTest --tests com.example.jariyo_backend.waitlist.WaitlistWorkflowIntegrationTests`
- `.\gradlew.bat build`
- `git diff --check`
- `git -C jariyo-docs diff --check`

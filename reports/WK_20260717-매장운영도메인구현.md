# 개요
이슈 #3의 범위인 매장 운영 도메인 워크스트림을 구현했다.

매장, 매장 정책, 서비스, 직원 가능 서비스, 영업시간, 직원 스케줄, 일정 예외를 조회할 수 있도록 스키마와 조회 API를 추가했고, 시드 데이터를 함께 넣어 바로 응답이 나오도록 구성했다.

# 이슈
- 현재 구현은 조회 중심이다.
- 예약 가능 시간 계산과 관리자용 수정 API는 아직 이슈 범위 밖으로 남아 있다.
- 시드 데이터는 MVP 확인용 기본값이므로 실제 운영 데이터와는 분리해야 한다.

# 후속 작업
- 예약 가능 시간 계산 API를 붙여서 매장 운영 데이터와 연결한다.
- 관리자용 수정 API를 추가해 영업시간, 정책, 직원 스케줄을 변경할 수 있게 한다.
- 매장 목록/상세 응답에 필요한 정렬과 필터 정책을 후속 이슈에서 확정한다.

# 셀프리뷰
- 문서 기준과 구현 범위를 먼저 맞춘 뒤 작업했다.
- 테스트는 통과했지만, 현재는 예시 데이터 기반의 조회 골격이라 운영용 권한 검증과 수정 흐름은 추가 작업이 필요하다.
- 리포트와 문서 업데이트를 함께 남겨 후속 이슈가 이어받기 쉽게 정리했다.

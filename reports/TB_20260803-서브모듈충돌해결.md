# 개요

- PR #46의 `jariyo-docs` 서브모듈 포인터 충돌을 해결했다.
- `master`가 가리키는 문서 커밋과 PR 브랜치 문서 커밋을 `jariyo-docs`에서 병합한 뒤, backend PR 포인터를 병합 커밋으로 갱신했다.

# 변경 파일

- `jariyo-docs`
- `reports/TB_20260803-서브모듈충돌해결.md`

# 실행 명령

- `gh pr view 46 --json number,title,headRefName,baseRefName,state,mergeStateStatus,url`
- `gh pr diff 46`
- `git -C jariyo-docs merge --no-ff 9d2e2c2f38c4a5dd1e3e58183137c771d0972e34`
- `./gradlew test`
- `git merge master`

# 테스트 결과

- `./gradlew test`: 성공
- `git merge master`: 실행 예정

# 이슈

- `jariyo-docs` 병합 커밋은 `merge/pr46-submodule` 브랜치로 분리해 원격에 올렸다.
- backend PR는 해당 병합 커밋을 참조하도록 갱신해야 GitHub 병합 충돌이 해소된다.

# 후속 작업

- backend PR 브랜치에 충돌 해결 커밋을 푸시한다.
- 필요하면 `jariyo-docs`에서도 `merge/pr46-submodule` 정리 PR을 연다.

# 셀프리뷰

- 충돌 원인이 backend 코드가 아니라 서브모듈 포인터 분기임을 확인했다.
- 사용자 작업트리는 건드리지 않도록 `/tmp` 복제본에서 해결 절차를 진행했다.
- 테스트는 통과했고, `master` 병합 검증 결과만 추가 반영하면 된다.
